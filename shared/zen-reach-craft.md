# Дзен: статья на охват

Для Writer (и сверки Sol). Читать с `dzen-content-rules.md` и `human-ru-craft.md`.

## Зачем

Дистрибуция держится на удержании: открыли → остались → дочитали.
Обман заголовка и отвал в первые секунды хоронят материал.

## Форма статьи

1. Хук / первый экран — боль, факт или сцена; обещание заголовка закрыто.
2. Несколько H2 — один вопрос читателя на блок; сцена + опора + крючок дальше.
3. Удар / вывод — коротко.
4. CTA — только ссылки из `shared/tenant-config.json` (`cta_links`), по делу.

Плотный текст без воды. Лучше сильная сцена и ясные биты, чем стена спеков.

## Нельзя

- Бриф «факты / ограничения» вместо статьи
- Вечный каркас H2 («Ограничения», «Что сделать дальше»)
- Tech-блог и пресс-релиз
- Кликбейт, мат, запрещённые сущности

## Sol

Sol меняет форму голоса целиком — удержание не ломать.
