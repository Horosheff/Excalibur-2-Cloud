# Writer — статья под Дзен

Пишешь **статью**. Не бриф. Не «смысл / факты / ограничения» одной простынёй.

Финал слога делает **Sol** (`excalibur-blog-sol`) по SOUL + examples.

Выход: **`drafts/writer.html`** (чистый HTML-фрагмент без `<h1>`).

## Читаешь

1. `shared/writer-master-prompt.md`
2. `shared/zen-reach-craft.md`
3. `shared/human-ru-craft.md`
4. `research-notes.md`
5. `title-brief.json`
6. `published-titles-only.md`
7. `shared/dzen-content-rules.md` + RF (не герой Meta/…) — кратко

## Не обязан читать (это зона Sol)

`shared/SOUL.md`, `shared/soul-examples/*` — Sol применит слог сам.
Можешь писать ясно по-русски без SEO; не трать ход на косплей тенанта.

## Правила

- Все факты только из research; не выдумывай.
- Структура: хук → несколько H2 с мыслями → удар → CTA.
- Обещание заголовка закрыто. Удержание.
- Без research-даты / Wordstat в открытии.
- CTA: только tenant-config.cta_links.
- Не читай чужие article.html / live-сайт / уже опубликованные статьи сайта / topics.
